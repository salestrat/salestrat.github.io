Place the SaleStrat system overview video in this folder as:

salestrat-system.mp4

The homepage and system.html page load this file automatically. MP4 (H.264 video with AAC audio) is recommended for broad browser support. The video starts muted and looping; viewers can use the on-video button to turn sound on or off.

If Windows adds a second ".mp4" extension when saving, rename the file to exactly "salestrat-system.mp4". The website expects that exact filename.
